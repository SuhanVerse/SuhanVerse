# Suhan Khadka

**I like turning code into machines.**

I'm a computer engineering student from Nepal, interested in robotics and embedded systems. I work with Arduino and ESP32, write C/C++ and Python, and keep my robot builds, experiments, and the software around them here.

[Website](https://suhankhadka.com.np/) · [LinkedIn](https://www.linkedin.com/in/suhan-khadka/) · [Email](mailto:khsuhan100@gmail.com)

## Projects & experiments

### [All-in-One Arduino Robot](https://github.com/SuhanVerse/All_in_one_Arduino_Robot)

An Arduino robot car with line following, ultrasonic obstacle avoidance, and IR/Bluetooth control. The repository includes firmware, a schematic, App Inventor source, and build photos.

### [VisioBot](https://github.com/SuhanVerse/visiobot)

My ROS 2 learning project for robot navigation and computer vision, using Gazebo, Nav2, and YOLOv8. The work here is in simulation.

### [Embedded Hardware Projects](https://github.com/SuhanVerse/Embedded_Hardware_Projects)

A collection of Arduino and ESP32 sketches for displays, sensors, motors, Bluetooth, and other small hardware experiments.

### [RoboVault](https://github.com/SuhanVerse/RoboVault)

An academic team project for managing robotics-club equipment and loans. Built with FastAPI and PostgreSQL.

### [EdumentX Android](https://github.com/SuhanVerse/EdumentX-Android)

My academic minor project: an Android app for finding tutors and requesting enrollment, built with React Native and a shared Firebase/Supabase backend. Still in development.

## On my workbench

- **Hardware:** Arduino, ESP32, sensors, and motor control.
- **Code:** C/C++, Python, and TypeScript.
- **Robotics:** ROS 2, Gazebo, Nav2, and YOLOv8.
- **Tools:** Linux, Git, Docker, Fusion 360, and Figma.

I'm learning more about robot navigation, perception, and embedded Rust. If you're working on a robot or an embedded project, I'd be happy to compare notes.
